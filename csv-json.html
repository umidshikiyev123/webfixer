🔄 CSV ⇄ JSON Konvertoru

CSV-ni JSON-a, JSON-u CSV-yə çevirin. Azərbaycan Excel-i üçün nöqtəli vergül dəstəyi.

Alət nə edir?

CSV (cədvəl mətni) və JSON (proqramların işlətdiyi format) arasında hər iki istiqamətdə çevirmə aparır. Excel və ya Google Sheets-dən kopyaladığınız cədvəli JSON-a, API cavabını isə Excel-də açılan CSV-yə çevirə bilərsiniz.

Ayırıcı problemi

Azərbaycan və Avropa ölkələrində Excel adətən vergülü onluq ayırıcı kimi işlətdiyinə görə CSV-də sütunları nöqtəli vergül (;) ilə ayırır. Alət CSV-nin ayırıcısını (vergül, nöqtəli vergül, tab, şaquli xətt) avtomatik tanıyır.

Məxfilik

Mətn və fayllar brauzerinizdə işlənir, serverə göndərilmir. Fayl yükləmə limiti 5 MB-dır.

Ətraflı bələdçi

CSV (cədvəl mətni) və JSON (proqramların işlətdiyi format) arasında hər iki istiqamətdə çevirmə aparır. Excel və ya Google Sheets-dən kopyaladığınız cədvəli JSON-a, API cavabını isə Excel-də açılan CSV-yə çevirə bilərsiniz.

Faydalı məsləhətlər

  • Birinci sətirdə sütun adları varsa, "Birinci sətir sütun adlarıdır" xanasını işarələyin: nəticə obyektlər massivi olacaq.
  • Sıfırla başlayan kodlar (məsələn 007) mətn kimi saxlanılır, ədədə çevrilmir.
  • JSON → CSV çevirməsində .csv faylı Excel-də Azərbaycan hərfləri düzgün görünsün deyə UTF-8 BOM ilə endirilir.
  • İç-içə obyektlər CSV xanasında JSON mətni kimi yazılır.

Tez-tez verilən suallar

CSV faylında vergül və dırnaq necə işlənir?

Dırnaq içindəki vergül, sətir keçidi və iki dırnaq ("") standart CSV qaydasına uyğun düzgün oxunur və yazılır.

JSON-un hansı forması dəstəklənir?

Obyektlər massivi ([{...},{...}]), massivlər massivi və tək obyekt. Fərqli açarlı obyektlərdə bütün açarlar sütun olur.

Excel-də Azərbaycan hərfləri pozulur, nə etməli?

Endirilən .csv faylı UTF-8 BOM ilə yazılır, Excel onu düzgün açır. Faylı iki dəfə klikləyib açın, Mətndən idxal etməyə ehtiyac yoxdur.

Çox böyük fayllar üçün uyğundurmu?

5 MB-a qədər rahat işləyir. Daha böyük məlumat üçün proqramlaşdırma dilindəki CSV kitabxanalarından istifadə edin.
