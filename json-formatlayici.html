🧩 JSON Formatlayıcı

JSON-u səliqəyə salın, sıxışdırın və səhvlərini sətir/sütun ilə tapın.

Nə üçündür?

API cavabını, konfiqurasiya faylını və ya məlumat nümunəsini oxunaqlı formata salmaq (formatla), ölçüsünü azaltmaq (sıxışdır) və düzgünlüyünü yoxlamaq üçün.

Səhv tapmaq

JSON yanlışdırsa, alət səhvin yerini sətir və sütun nömrəsi ilə göstərir. Ən çox rast gəlinən səhvlər: son elementdən sonra artıq vergül, tək dırnaq (JSON-da yalnız qoşa dırnaq olur), dırnaqsız açar adları və yarımçıq mötərizələr.

Məxfilik

JSON məzmunu serverə göndərilmir, emal brauzerinizdə gedir.

Ətraflı bələdçi

JSON API cavablarında, konfiqurasiya fayllarında və məlumat mübadiləsində ən çox istifadə olunan formatdır. Bu alət JSON-u oxunaqlı (girintili) formaya salır, ölçüsünü azaltmaq üçün sıxışdırır və düzgün olub-olmadığını yoxlayır. Səhv olduqda xətanın sətir və sütun nömrəsini göstərir ki, tez tapıb düzəldə biləsiniz.

Faydalı məsləhətlər

  • JSON-da açarlar və mətn dəyərləri yalnız cüt dırnaqla ("...") yazılır. Tək dırnaq səhvdir.
  • Son elementdən sonra vergül qoymaq ən çox rast gəlinən səhvlərdəndir ({"a":1,} yanlışdır).
  • Açarları əlifba sırası ilə düzmək iki JSON-u müqayisə edəndə faydalıdır.
  • Məxfi API açarlarını və şəxsi məlumatları ictimai alətlərə yapışdırmaqdan ehtiyatlı olun. Bu alət heç nə göndərməsə də, ümumi qayda belədir.

Tez-tez verilən suallar

Formatlama JSON-un mənasını dəyişirmi?

Xeyr. Yalnız boşluqlar və sətir sonları dəyişir, məlumat eyni qalır.

Şərh (comment) yazmaq olarmı?

Standart JSON-da şərh yoxdur. Şərhli fayl (JSONC) bu alətdə səhv kimi göstərilə bilər.

Çox böyük JSON işləyirmi?

Bir neçə meqabayta qədər rahat işləyir. Daha böyük fayllar brauzeri yavaşlada bilər.

JSON necə formatlanır?

Bu alət JSON mətnini səliqəyə salır, lazım olduqda sıxışdırır və səhvləri sətir və sütun nömrəsi ilə göstərir. JSON-u yapışdırın, alət onu oxunaqlı formada təqdim edir.

Nə üçün faydalıdır?

  • API cavablarını və konfiqurasiya fayllarını oxumaq üçün faydalıdır.
  • Vergül, dırnaq və ya mötərizə səhvlərini tez tapmağa kömək edir.

Tez-tez verilən suallar

JSON səhvi necə tapılır?

Alət səhvin olduğu sətir və sütunu göstərir, həmin yerə baxmaq kifayətdir.

JSON-u sıxışdırmaq nə üçün lazımdır?

Boşluqlar çıxarılır və fayl ölçüsü kiçilir, bu da ötürmə üçün rahatdır.
