Güclü parol necə olmalıdır?

  • Ən azı 14–16 simvol uzunluğunda olmalıdır.
  • Böyük və kiçik hərf, rəqəm və simvol qarışığı olmalıdır.
  • Hər sayt üçün fərqli parol istifadə edin.
  • Parolları parol menecerində saxlayın.

Təhlükəsizlik

Parollar brauzerinizin təhlükəsiz təsadüfi ədəd generatoru (crypto.getRandomValues) ilə yaradılır və heç bir yerə göndərilmir. "Güc" göstəricisi entropiya (bit) hesabına əsaslanır: 64 bitdən yuxarı güclü, 100 bitdən yuxarı çox güclü sayılır.

Ətraflı bələdçi

Zəif və təkrar istifadə olunan parollar hesabların oğurlanmasının əsas səbəbidir. Bu alət təsadüfi, güclü parollar, hex açarlar və API tokenlər yaradır. Generasiya brauzerin kriptoqrafik təsadüfi ədəd mexanizmi ilə edilir, yəni nəticələri proqnozlaşdırmaq mümkün deyil. Yaranan parol heç bir yerə göndərilmir.

Faydalı məsləhətlər

  • Hər sayt üçün ayrı parol istifadə edin. Biri sızsa, qalan hesablar təhlükəyə düşməsin.
  • Uzunluq mürəkkəblikdən vacibdir: 16 və daha çox simvol uzunluğunda təsadüfi parol praktiki olaraq sındırıla bilməz.
  • Parolları yadda saxlamaq əvəzinə parol meneceri (məsələn brauzerin daxili meneceri və ya ayrıca proqram) istifadə edin.
  • Mümkün olan yerdə iki mərhələli doğrulamanı (2FA) aktiv edin.

Tez-tez verilən suallar

Yaranan parollar harada saxlanılır?

Heç harada. Parol yalnız ekranınızda yaranır, biz onu görmürük və saxlamırıq. Səhifəni bağladıqda yox olur.

Ən təhlükəsiz parol uzunluğu nə qədərdir?

Gündəlik hesablar üçün 14-16 simvol, vacib hesablar (e-poçt, bank) üçün 20 və daha çox simvol məsləhətdir.

Hex açar və token nə üçündür?

Proqramçılar bunları API açarı, sessiya tokeni və ya şifrələmə üçün gizli dəyər kimi istifadə edir.
