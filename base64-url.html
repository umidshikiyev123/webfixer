🔣 Base64 / URL Kodlayıcı

Mətni Base64 və URL formatına kodlayın və geri açın (UTF-8, Azərbaycan hərfləri ilə).

Base64 nədir?

Base64 mətni və ya ikili məlumatı yalnız hərf, rəqəm və bir neçə simvoldan ibarət mətnə çevirən kodlaşdırmadır. E-poçt, JSON və URL daxilində məlumat ötürəndə işlədilir. Bu şifrələmə deyil, hər kəs onu geri aça bilər, ona görə gizli məlumatı qorumaq üçün istifadə etməyin.

URL kodlaşdırma

Linkdə boşluq, &, = və Azərbaycan hərfləri kimi simvollar %20, %26, %C9%99 formasına salınır. Alət UTF-8 ilə işləyir, ə, ş, ç kimi hərflər düzgün çevrilir.

Base64URL

Linklər üçün təhlükəsiz variantdır: + və / əvəzinə - və _ işlədilir, sondakı = silinir (JWT və API tokenlərində rast gəlinir).

Ətraflı bələdçi

Base64 və URL kodlaşdırma proqramçıların hər gün rast gəldiyi çevirmələrdir. Base64 mətni və ya ikili məlumatı yalnız təhlükəsiz simvollardan ibarət sətrə çevirir, URL kodlaşdırma isə linkdə xüsusi simvolları (boşluq, &, =, ə, ş və s.) % ilə başlayan formada yazır. Alət UTF-8-i düzgün işləyir, ona görə Azərbaycan hərfləri pozulmur.

Faydalı məsləhətlər

  • Base64 şifrələmə deyil, sadəcə kodlaşdırmadır. Hər kəs onu geri aça bilər, parol və ya gizli məlumatı onunla qorumaq olmaz.
  • Linkdə istifadə üçün Base64URL variantını seçin: + və / simvollarının yerinə - və _ yazılır.
  • Axtarış parametrlərini (məsələn ?q=salam dünya) göndərməzdən əvvəl URL kodlayın.

Tez-tez verilən suallar

Base64 nə üçün işlədilir?

E-poçt əlavələrində, JSON-da şəkil ötürmək üçün, HTTP başlıqlarında və tokenlərdə məlumatı mətn şəklində daşımaq üçün.

Niyə açanda xəta çıxır?

Sətir düzgün Base64 deyil, ya da kəsilib. Boşluq və ya artıq simvolların olmadığını yoxlayın.

Daxil etdiyim mətn serverə göndərilirmi?

Xeyr, çevirmə brauzerdə aparılır.
